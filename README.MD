Простые моды для Лохотронщика Crazy Loto в том числе демо версии.

Рекомендуется сначала запатчить полную игру от nocd+пути(демо запатчено):
https://github.com/bagdenisov/crazyloto-patch
Также если под современной виндой проблемы или под Линуксом: 
https://github.com/FunkyFr3sh/cnc-ddraw/

Мод использует winmm.dll с проекта:
https://github.com/ThirteenAG/Ultimate-ASI-Loader

Для Линукс через протон/wine: winmm.dll=n,b

Настройки мода в файле crazy_loto_tweaks.ini
